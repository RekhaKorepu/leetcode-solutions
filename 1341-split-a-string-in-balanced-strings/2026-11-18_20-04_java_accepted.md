## Solution

```java
class Solution {
    public int balancedStringSplit(String s) {
        int n=s.length();
        int rcount=0;
        int lcount=0;
        int ans=0;
        for(int i=0;i<n;i++){
            char ch=s.charAt(i);
            if(ch=='R'){
                rcount++;
            }
            if(ch=='L'){
                lcount++;
            }
            if(rcount==lcount){
                ans++;
                lcount=0;
                rcount=0;
            }
        }
        return ans;   
    }
}
```
