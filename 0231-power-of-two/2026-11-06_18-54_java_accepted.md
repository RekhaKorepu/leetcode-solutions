## Solution

```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        // The important observation here is if the number is
        //power of 2, then if we do & operation with previous number the result is 0, (this is Bit manipulation)

        if(n<=0){
            return false;
        }

        return (n & (n-1))==0;
    }
}
```
