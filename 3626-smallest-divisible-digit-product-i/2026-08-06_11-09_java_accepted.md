## Solution

```java
class Solution {
    public int smallestNumber(int n, int t) {
        int number=n;
        while(true){
            int product=digitProduct(number);
            if(product%t==0){
                return number;
            }
            number++;

        }
         
    }
    public int digitProduct(int number){
        int product=1;
        while(number>0){
            int rem=number%10;
            product*=rem;
            number=number/10;
        }
        return product;
    }
}
```
