## Solution

```java
class Solution {
    public String removeDigit(String number, char digit) {
        int n=number.length();
        for(int i=0;i<n;i++){
            if(number.charAt(i)==digit){
                if(i+1<n && number.charAt(i+1)>digit){
                    return number.substring(0,i)+number.substring(i+1);
                }
            }
                 
        }
        // if the 'if' condition is false everytime, then we find last occurence of digit and remove it.
        int lastIndex = number.lastIndexOf(digit);
        return number.substring(0, lastIndex)+number.substring(lastIndex+1);    
    }
}
// Start checking the string from left to right.
// Find an occurrence of the digit we need to remove.
// Check whether the next character is greater than that digit.
// If yes, remove the current occurrence and return the result immediately.
// If no suitable occurrence is found, remove the last occurrence instead.
```
