## Solution

```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {

        // Note for circular aray you should traverse array twice so, i should start from i=2*n-1
        // i%n since, circular
        //Only update the ans array once i<n. Because upto this all greater elements are stored in stack.

        int ans[]= new int[nums.length];
        int n= nums.length;
        Stack<Integer> st= new Stack<>();
        for(int i=2*n-1; i>=0; i--){
            int index= i%n;
            while(!st.empty() && nums[index]>= st.peek()){
                st.pop();
            }
            if(i<n){
                if(st.empty()){
                    ans[index]=-1;
                }else{
                    ans[index]=st.peek();
                }
            }
            st.push(nums[index]);
        }
        return ans;

        
    }
}
```
