## Solution

```java
class Solution {
    public boolean checkString(String s) {
        char prev=s.charAt(0);
        int n=s.length();
        for(int i=1;i<n;i++){
            if(prev=='b' && s.charAt(i)=='a'){
                return false;
            }
            prev=s.charAt(i);
        }
        return true;
        
    }
}
```
