## Solution

```java
class Solution {
    public boolean checkSubarraySum(int[] nums, int k) {
        HashMap<Integer,Integer> rem_map= new HashMap<>();
        rem_map.put(0,-1);
        int prefixsum=0;
        for(int i=0;i<nums.length;i++){
            prefixsum+=nums[i];
            int remainder=prefixsum%k;
            if(rem_map.containsKey(remainder)){
                if(i-rem_map.get(remainder)>=2){
                    return true;
                }
            }else{
                rem_map.put(remainder,i);
            }
        }
        return false;
        
    }
}
```
