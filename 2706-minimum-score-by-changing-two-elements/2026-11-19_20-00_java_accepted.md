## Solution

```java
class Solution {
    public int minimizeSum(int[] nums) {
        // Important Greedy observation
        //  Whenever a problem asks you to minimize the maximum difference after modifying a fixed number of elements:
        //  Sort the array.
        //  Focus on the smallest and largest elements.
        //  Consider the possible ways to eliminate extreme elements.
        //  Choose the minimum remaining range.
        int n = nums.length;

        if (n <= 3) {
            return 0;
        }

        Arrays.sort(nums);

        int case1 = nums[n - 1] - nums[2];

        int case2 = nums[n - 2] - nums[1];

        int case3 = nums[n - 3] - nums[0];

        return Math.min(case1, Math.min(case2, case3));
        
    }
}
```
