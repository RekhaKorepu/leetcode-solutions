## Solution

```java
class Solution {
    public int diagonalSum(int[][] mat) {
        int n= mat[0].length;
        int sum=0;
        for(int i=0;i<n;i++){
            sum += mat[i][i];
            sum += mat[i][n-1-i];

        }
        if(n%2 !=0){ //if it odd numbered square matrix, middle diognal element repeats.
          sum= sum- mat[n/2][n/2];

        }
        return sum;
        
    }
}
```
