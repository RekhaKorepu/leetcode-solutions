## Solution

```java
class Solution {
    public boolean canAliceWin(int n) {
        if(n<10){
            return false;
        }
        boolean isAlice = true;
        int current=n-10;
        int intial=9;
        while(true){
            if(current-intial<0){
                break;
            }
            isAlice=!isAlice;
            current=current- intial;
            intial=intial-1;


        }
        return isAlice;
        
    }
}
```
