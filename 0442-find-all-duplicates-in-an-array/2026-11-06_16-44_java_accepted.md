## Solution

```java
class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        List<Integer> res = new ArrayList<>();
        //Hashmap approach T: o(n), S: o(n)

        //index marking approach o(n) o(1)

        for(int i=0;i<nums.length;i++){
            
            int index = Math.abs(nums[i])-1;
            if(nums[index]>0){
               nums[index]=-nums[index];
            }
            else{
                res.add(Math.abs(nums[i])); //because when we detect a duplicate we have to add current number
            }
        }
        return res;
        
    }
}
```
