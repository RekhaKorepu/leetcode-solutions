## Solution

```java
class Solution {
    public int integerReplacement(int n) {
        int ans=0;
        long num=n;
        while(num!=1){
            if(num%2==0){
                num=num/2;
                ans++;
            }else{
                //we are checking whether num is divisible by 4, so that it takes less steps to make 1.
                if(num==3 || num%4==1){ //We handle it separarely for 3, because it if we do +1, it takes 3 steps, -1 takes 2 steps only.
                    num=num-1;
                }
                if(num%4==3){
                    num=num+1;
                }
                ans++;
            }
        }
        return ans;
        
    }
}
```
