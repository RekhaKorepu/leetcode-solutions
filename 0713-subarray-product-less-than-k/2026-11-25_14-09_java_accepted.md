## Solution

```java
class Solution {
    public int numSubarrayProductLessThanK(int[] nums, int k) {
        int left=0;
        int right=0;
        int product=1;
        int count=0;
        if(k<=1){
            return 0;
        }
        while(right<nums.length){
            product*=nums[right];

            while(left<nums.length && product>=k){
                product=product/nums[left];
                left++;
            }

            count= count+right-left+1;
            right++;
        }
        return count;
        
    }
}
```
