## Solution

```java
class Solution {
    public String longestPalindrome(String s) {
                int n=s.length();
                  int start=0;

        boolean dp[][]= new boolean[n][n];
        for(int i=0;i<n;i++){
            dp[i][i]=true;  //because every single char is palindrome
        }
        int maxLen=1;

        for(int len=2;len<=n;len++){
            for(int i=0;i<=n-len;i++){
                int j=i+len-1; // i--> start index, len--> length of string-> -1 for index
               if(s.charAt(i)==s.charAt(j)){
                if(len<=3){
                    dp[i][j]=true;
                }else{
                    dp[i][j]= dp[i+1][j-1];
                }
               }

               if(dp[i][j]==true && len>maxLen){
                  maxLen=len;
                  start=i;

               }
            }

        }

        return s.substring(start, start+maxLen);
        
    }
}
// Longest Palindromic Substring – DP Approach

// 1. State
// - Use a 2D boolean array dp[i][j].
// - dp[i][j] = true means substring s[i...j] is a palindrome.
// 2. Initialization
// - Every single character is a palindrome.
// - Initialize dp[i][i] = true.
// - Initialize start = 0 and maxLen = 1.
// 3. Transition
// - Compare the outer characters s[i] and s[j].
// - If they are different, the substring is not a palindrome.
// - If they are equal:
//   - For length 2 or 3, it is automatically a palindrome.
//   - For length greater than 3, check whether the inner substring is a palindrome: dp[i+1][j-1].
// 4. Traversal
// - Traverse substring lengths from 2 to n.
// - For every length, iterate over all valid starting indices.
// - Calculate ending index using j = i + len - 1.
// - Increasing length ensures smaller DP states are already calculated.
// 5. Answer
// - Whenever dp[i][j] is true and len > maxLen, update start and maxLen.
// - Return s.substring(start, start + maxLen).
// Complexity
// - Time: \(O(n^2)\)
// - Space: \(O(n^2)\)
```
