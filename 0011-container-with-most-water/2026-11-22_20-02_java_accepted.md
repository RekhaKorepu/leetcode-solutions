## Solution

```java
class Solution {
    public int maxArea(int[] height) {
        int n=height.length;
        int max=Integer.MIN_VALUE;
        int i=0;
        int j=n-1;
        if(height==null){
            return 0;
        }
        while(i<j){
            if(height[i]<height[j]){
                max=Math.max(max, height[i]*(j-i));
                i++;
            }else{
                max=Math.max(max, height[j]*(j-i));
                j--;
            }
            
        }
        return max;

    }
}
```
