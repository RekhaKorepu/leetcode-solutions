## Solution

```java
class Solution {
    public int numTrees(int n) {
        int dp[]=new int[n+1];
        if(n<=0){
            return 0;
        }
        dp[0]=1; //left subtree/right subtree empty one possibility
        dp[1]=1;

        for(int nodes=2;nodes<=n;nodes++){
            for(int root=1; root<=nodes; root++){
                int left=root-1;
                int right=nodes-root;
                dp[nodes]= dp[nodes]+ dp[left]*dp[right];
            }
        }
        return dp[n];
        
    }
}
```
