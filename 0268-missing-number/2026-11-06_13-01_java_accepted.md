## Solution

```java
class Solution {
    public int missingNumber(int[] nums) {
        int n=nums.length;
        // long sum= (long) (n*(n+1)) / 2;
        // long num_sum=0;
        // for(int i=0; i<nums.length; i++){
        //    num_sum+= nums[i];
        // }

        // return (int) (sum - num_sum);
        int xor =0;
        for(int i=0; i<=n;i++){
            xor^=i;
        }
        for(int i=0;i<n;i++){
            xor^=nums[i];
        }
        return xor;
        
    }
}
```
