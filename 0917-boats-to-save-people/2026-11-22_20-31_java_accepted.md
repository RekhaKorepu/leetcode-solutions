## Solution

```java
class Solution {
    public int numRescueBoats(int[] people, int limit) {
        int max=0;
        int n=people.length;
        Arrays.sort(people);
        int i=0;
        int j=n-1;
        while(i<=j){
            int weightSum=people[i]+people[j];
            if(weightSum<=limit){
                i++;
     
            }
            j--;
            max++;
        }

    
        return max;   
    }
}
```
