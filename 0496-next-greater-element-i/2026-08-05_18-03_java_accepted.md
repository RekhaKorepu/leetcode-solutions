## Solution

```java
class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {

        // 1.Simply for every number in nums2, we are mapping it to next higher element.
        //2. If no greater element is found. they remain in stack and assigned -1 and stored in map.
        //3. Then for every num in nums1, took the ans from the map. 
        HashMap<Integer,Integer> map= new HashMap<>();
        Stack<Integer> st= new Stack<>();

        for(int num: nums2){
            while(!st.empty() && num>st.peek()){
                map.put(st.pop(), num);
            }
            st.push(num);
        }

        while(!st.empty()){
            map.put(st.pop(),-1);
        }
        int ans[]= new int[nums1.length];

        for(int i=0;i<nums1.length;i++){
            ans[i]=map.get(nums1[i]);

        }
        return ans;
        
    }
}
```
