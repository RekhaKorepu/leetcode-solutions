## Solution

```java
class Solution {
    public boolean canReach(String s, int minJump, int maxJump) {
        int n=s.length();
        //We are using DP approach (two possible postions) and sliding window approach here.

        boolean dp[]=new boolean[n];
        dp[0]=true;
        for(int i=1;i<n;i++){
            dp[i]=false;
        }

        int count=0;

        for(int i=1;i<n;i++){

            //we need to check whether there are any possibilities from i-minjump to i-maxjump

            //postion entering the window
            int index1=i-minJump;

            if(index1>=0 && dp[index1]==true){
                count++;
            }
            
            //postion leaving the current window
            int index2=i-maxJump-1;

            if(index2>=0 && dp[index2]==true){
                count--;
            }

            if(s.charAt(i)=='0' && count>0){
                dp[i]=true;
            } 

        }
        return dp[n-1];
        
    }
}
```
