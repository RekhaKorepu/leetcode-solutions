## Solution

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        int dp[]= new int[amount+1];
       
        Arrays.fill(dp, Integer.MAX_VALUE);
         dp[0]=0;

        for(int i=1;i<=amount;i++){
            for(int coin: coins){
                if(coin<=i && dp[i-coin] != Integer.MAX_VALUE){
                    dp[i]=Math.min(dp[i], 1+dp[i-coin]); // It means checking minimum dp i, or else considering current coin, and adding the coins required to make minimum amount.
                }
            }
        }
        if(dp[amount]==Integer.MAX_VALUE){
            return -1;
        }

        return dp[amount];
        
    }
}
```
